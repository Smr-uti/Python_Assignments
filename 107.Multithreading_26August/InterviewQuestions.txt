    Simple Tasks - Multi-threading set2
Task 1 — Basic thread with a result Create a Thread subclass that takes two numbers in its constructor, computes their sum in run(), and stores it in self.result. Start the thread, call join(), then print the result.
Task 2 — Thread names and IDs Create two threads using target=, give them custom names, and print each thread's name, ident, and native_id. Also print the main thread's name and ID using threading.current_thread().
Task 3 — Check thread status Start three threads that each sleep for a few seconds. Right after starting them, print threading.active_count() and loop through threading.enumerate() printing each thread's name. Then check is_alive() for each thread before and after they finish.


Simple Tasks - Multi-threading set3
Task 1 — Measure execution time with and without threads Write two functions that each simulate work using time.sleep(2). First, call them one after another normally and print total execution time using the time module. Then run the same two functions using threads (with join()) and print the total execution time again. Compare the two results.
Task 2 — Fix a race condition using Lock Create a BankAccount class with a balance attribute and a withdraw(amount) method. Without any locking, create two threads that both try to withdraw money from the same account at the same time when the balance is insufficient for both. Observe the race condition. Then fix it by adding a Lock around the critical section inside withdraw().
Task 3 — Limit concurrent access with Semaphore Simulate 5 threads trying to access a "resource" (e.g., print a message and sleep for 2 seconds), but only allow 2 threads to access it at the same time using a Semaphore(2). Print which thread enters and exits the critical section, and observe how threads wait for a slot to free up.
